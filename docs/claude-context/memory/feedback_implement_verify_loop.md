사용자가 자리를 비우거나 "오래 걸려도 됨" 식으로 명시하면, 구현 끝나고 보고/멈추지 말고 다음 루프를 자동 반복:

1. 구현
2. 빌드/verify 캡처
3. 콘솔/페이지 에러, 시각 mismatch 점검
4. 발견된 문제 수정
5. 다시 2번부터, 클린할 때까지

**Why:** 사용자가 자리에 없으면 한 사이클로 끝내봤자 다음 피드백 받을 때까지 idle. 사용자가 돌아왔을 때 "검증까지 다 끝낸 결과"가 있어야 가치 있음.

**How to apply:** 사용자 자리비움 신호("외출", "잠깐 나갔다 옴", "오래 걸려도 됨") 감지되면 verify 결과 기준 0 에러 + 시각 일치까지 자동으로 반복. 단, **destructive 작업(force push, DB drop 등)은 여전히 사용자 확인 필요**.
