PC 헤더(`PCHeader.jsx`) 로고는 `WDC`가 정답.

**Why:** Figma는 "PDDP(가안)"으로 표기되어 있지만 사용자가 명시적으로 "WDC가 맞음"이라고 확정. Figma 쪽이 outdated.

**How to apply:** Figma vs 코드 자산 감사 시 헤더 로고 텍스트는 mismatch로 보고하지 않음. 다른 헤더 요소(네비 항목, 우측 메뉴 등)는 일반 룰대로 비교.
