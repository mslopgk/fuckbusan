작업 도중 백엔드(`uvicorn`, 포트 8000), 프론트(`npm run dev`, 포트 8501) 같은 dev 서버를 띄웠을 때 **작업 끝났다고 임의로 kill하지 말 것**. 사용자가 검증 후 직접 만져보거나 다른 작업으로 이어가는 경우가 많음.

**Why:** 사용자가 "서버 종료하지 마셈"이라고 직접 요청. 매번 다시 띄우는 비용/대기시간 낭비, 그리고 검증 직후 직접 화면을 열어보고 싶을 때 흐름이 끊김.

**How to apply:**
- verify 도구 실행이나 API 검증을 위해 띄운 서버라도, 작업 종료 시점에 `kill $(lsof -ti:8000)` 같은 종료 명령을 자동으로 넣지 말 것
- 사용자가 명시적으로 "종료해", "stop server" 등을 말할 때만 종료
- background process가 살아있다면 그대로 둘 것 — 사용자에게 어떤 포트에 뭐가 떠있는지만 알려주면 됨
